# Correction Space Steering (CSS)

Official implementation of the paper:

**Correction Space Steering for Hallucination Mitigation in Large Vision-Language Models** (NeurIPS 2026).

CSS mitigates hallucinations in large vision-language models via a learned low-dimensional correction space and adaptive, input-conditioned activation steering at inference time—without updating backbone weights.
